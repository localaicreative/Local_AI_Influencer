# Produktivitäts-Tracking

## Metriken

### Git-Basiert (automatisch)
- Commits pro Woche
- Dateien erstellt/geändert
- Zeilen Code/Content hinzugefügt

### Content-Basiert
- Projekte gestartet / abgeschlossen
- Tutorials geschrieben
- Ebooks veröffentlicht
- Social Media Posts

### Zeit-Basiert
- Stunden investiert (manuell tracken)
- Sessions pro Woche

## Tracking-Skript

```bash
# Aktuellen Stand anzeigen
./scripts/track.sh status

# Neue Session starten
./scripts/track.sh start "Kinderbuch-Tutorial schreiben"

# Session beenden
./scripts/track.sh end
```

## Dashboard (einfach)

In `GOAL.md` wird jede Woche ein kurzer Status eingetragen:
- Was wurde erledigt?
- Wie viele Commits?
- Nächste Prioritäten?

---

*Tracking ist kein Selbstzweck — es zeigt Fortschritt und motiviert.*
