> Hermes Agent Tutorial — So habe ich die Apps gebaut _

Interaktives Tutorial mit kopierbaren Prompts | 6 Schritte | ~20 Min

Schritt 1: Hermes Agent installieren und konfigurieren

Zuerst brauchst du Hermes Agent lokal installiert. Hier ist der Prompt um das Setup zu starten:

Prompt 1 — Installation
Installiere Hermes Agent auf meinem System und konfiguriere ein erstes Profil. Ich habe LM Studio mit Qwen 3.6 27B auf localhost:1234 laufen.
Was passiert: Dieser Prompt lässt Hermes sich selbst installieren, das Profil erstellen und die Verbindung zu deinem lokalen LM Studio-Server herstellen. Du kannst den Prompt direkt in die CLI kopieren: hermes chat -q "..."
Tipp: Wenn du bereits ein Profil hast, springe direkt zu Schritt 3 und passe den Prompt an deine Bedürfnisse an.

Schritt 2: Dein erstes Skill erstellen

Skills sind wiederverwendbare Workflows. Lass uns einen einfachen Research-Skill bauen:

Prompt 2 — Skill erstellen
Erstelle einen neuen Skill namens 'research-collector' der automatisch nach neuen AI/ML News sucht, sie bewertet und im Research-Inbox speichert. Verwende das Coding Quality Gate Framework.
Was passiert: Hermes erstellt den Skill mit SKILL.md, Templates und Scripts. Das Coding Quality Gate stellt sicher, dass der Code sauber ist und Best Practices folgt.

Schritt 3: Cronjob für automatische Research setzen

Mach aus dem Skill einen autonomen Job der regelmäßig läuft:

Prompt 3 — Cronjob erstellen
Richte einen Cronjob ein der den research-collector Skill täglich um 11:00, 16:00 und 21:00 Uhr ausführt. Die Ergebnisse sollen lokal gespeichert werden.
Was passiert: Drei Cronjobs werden erstellt die den Research-Skill automatisch ausführen. Die Ergebnisse landen im Research-Inbox deines Profils.

Schritt 4: Dashboard für Monitoring bauen

Jetzt brauchen wir eine Übersicht über Hardware, Research und Blog-Drafts:

Prompt 4 — Dashboard
Baue ein Flask-Dashboard auf Port 8888 das Hardware-Metriken (GPU, CPU, RAM, PSU), Research-Inbox Items, Blog-Drafts und Cronjob-Status anzeigt. Verwende dark theme mit monospace Font.
Was passiert: Hermes erstellt server.py mit allen API-Endpunkten und einem inline HTML/CSS/JS Dashboard. Das Ergebnis ist genau das Dashboard was du jetzt siehst!

Schritt 5: Blog-Automatisierung einrichten

Vom Research-Inbox zum veröffentlichten Blog-Artikel:

Prompt 5 — Auto-Curation
Erstelle einen wöchentlichen Cronjob der die besten Research-Inbox Items identifiziert, Blog-Vorschläge generiert und automatisch Drafts erstellt. Die Drafts sollen im blog-drafts/ Ordner landen.
Was passiert: Ein Auto-Curation Job läuft sonntags um 10:00 Uhr, bewertet die Research-Items nach Blog-Potential und erstellt fertige Draft-Skelette mit Zusammenfassungen.

Schritt 6: Supervision und Wartung

Stelle sicher dass alles sauber läuft:

Prompt 6 — Supervision
Richte einen wöchentlichen Supervision-Job ein der prüft: Framework-Konsistenz, Skill-Audit (veraltete Skills identifizieren), Cronjob-Health und generiert einen Report.
Was passiert: Der Supervision-Job prüft alle Skills auf Konsistenz, identifiziert veraltete Kandidaten und erstellt einen wöchentlichen Health-Report.
