# Which Local AI Model Should You Run on a Raspberry Pi 5?

## Zusammenfassung

I ran 8 local AI models on a Raspberry Pi 5 to answer two questions: is there any real value in running an LLM on a Pi, and which model should you actually use?

Every model got the same setup and the same four practical tasks. I measured generation speed in tokens per second and how long each one takes to start answering. Then I sorted them into three groups: usable for chat, usable only for background tasks, and ones you can skip.
